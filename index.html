A small Workshop interface for custom skills

Brett,

Workshop authors could give players more skill variety by combining actions the game already knows how to run. Authors could make a new skill without needing another built-in preset. The local prototype is a starting point for discussing an official interface owned by the game.

Suggested interface

  1. Load and validate skill definitions from a Workshop data file.
  2. Let a custom class reference a validated skill ID as its signature move.
  3. Have the game execute a bounded list of allowlisted actions in order, using native damage and healing resolution.

The filename workshop-skills.json, class field callingSkillId, and fields below are illustrative proposals. This excerpt follows target selection and landing validation. The last action is optional and runs only when the native attack reports a hit.

{
  "actions": [
    { "type": "strikeFromLanding", "landing": "landing", "power": 1, "as": "strike" },
    { "type": "drainMana", "result": "strike", "when": "hit", "amount": 15 }
  ]
}

Workshop files supply data only. The game owns the action handlers and conditions. Report unknown actions, invalid values, and missing references with the source file and field path. For duplicate IDs, identify the conflicting files and mark that ID unavailable. Fall back to the original calling only for affected bindings. Unbound classes keep their native behavior.

Verified in the local prototype

First Aid, Blink Slash, and Flash Strike share one executor in the Sparring Ring of the fixed 3.04 HTML5 build. Flash Strike used a new skill JSON and a test binding change. In the same-seed comparison, both attacks hit the same target for the same HP loss, and only Blink Slash drained 15 mana. Both skills also fired again after their natural cooldowns in one bout.

Suggested scope and open checks

The prototype binds explicit test instance IDs. Class-level Workshop binding is the proposed extension. The current executor allows up to eight steps with one main resolution, and blink and attack remain one action. Steam, Workshop subscriptions, delves, and seasons are untested.
